# Tom Sira

Website von Tom Sira – ambient / slow electronic, Vinyl, mobiles Soundsystem.

- `index.html` – die komplette Seite (HTML, CSS, JS in einer Datei)
- `img/` – Fotos, `audio/` – Tracks
- `_headers`, `netlify.toml` – Einstellungen für Netlify (kein Build)

Lokal ansehen: Ordner mit einem beliebigen statischen Server öffnen, z. B. `python3 -m http.server`.
